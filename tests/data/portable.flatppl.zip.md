`portable.flatppl.zip` is the shared Rust bundle fixture, written with Info-ZIP
3.0 (`zip -X -r -y`) and checked with `unzip -t`. It contains a Normal prior,
observations `[1, 2]`, binary bytes, a relative symlink, and a nested archive.
The log density at zero is `-1.5*log(2*pi) - 2.5`, with derivative `3`.
